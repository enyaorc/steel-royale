# STEEL ROYALE

three.js製 クォータービュー・ロボットバトルロイヤル。自機以外はAI。倒されてもスコア -50 で何度でも復活。

## 起動
- `index.html` をブラウザで開く（または `start.bat`）。ビルド済みの `dist/game.js` を読み込むのでサーバ不要。

## 操作
| 入力 | 動作 |
|---|---|
| WASD | 移動（画面基準） |
| マウス | 照準 |
| 左クリック | 通常攻撃（長押しで連射） |
| 1 / 2 / 3 | スキル |
| 4 | ウルト（ゲージ100%） |
| SPACE | ブースト |
| TAB | スコアボード |
| ホイール | カメラ距離 |
| ESC | ポーズ |

キー割り当ては設定画面で変更可能。

### スマホ（タッチ）操作
- 左スティック：移動 / 右スティック：通常攻撃の方向（倒している間連射、タップで自動照準射撃）
- スキル・ウルト：押したまま射出方向へフリックして離す（フリック距離で着弾距離）。タップのみで自動照準。ボタン上へ戻して離すとキャンセル
- ブースト：左スティック方向へダッシュ
- 画面に触れるとタッチ操作、マウス/キーボードを使うとPC操作に自動で切り替わる（設定で固定可能）。横画面専用

## ルール
- 撃破 +100 / アシスト +30 / 被撃破 -50。制限時間終了時のスコア順で順位決定。
- 5秒後に復活（2秒無敵）。安全地帯（青い壁）は時間で縮小し、外にいるとダメージ。
- 補給ポッド：緑=修理、青=コア（ウルト+30%・EN全快）。
- TrueSight（視界システム）：自機から見えない範囲は暗転し、そこにいる敵・弾・設置物は表示されない（ミニマップにも出ない）。高さ2m以下の木箱や柵は越して見える。設定で ON/OFF・暗さを変更可能。

## チーム制圧モード
- 青チーム vs 赤チーム（プレイヤーは青）。機体数設定を2等分。安全地帯の縮小なし。
- 拠点 A〜E の円内に留まるとゲージが進み占拠（味方が多いほど速い／敵味方が同時にいると停止／敵拠点は中立化してから奪う）。
- 占拠中の拠点1つにつき毎秒1点。目標点（5分で750点）に先に到達するか、時間切れで多い方が勝利。
- 撃破はチーム得点に影響しない。味方への攻撃は無効。復活は自陣の出撃地点。味方が視認している敵は表示される。

## 機体
VANGUARD（アサルト）/ TITAN（ヘビー）/ PHANTOM（スナイパー）/ RAZOR（ブローラー）/ WARDEN（エンジニア）/ INFERNO（パイロ）。各機体に通常攻撃・スキル3種・ウルト1種。

## 開発
```
npm install
npm run build   # dist/game.js を生成
npm run watch   # 監視ビルド
```
3Dモデル・テクスチャ・アイコン・効果音・BGMはすべてコードで手続き生成（`src/models.js`, `src/textures.js`, `src/icons.js`, `src/audio.js`）。

## 構成
- `src/main.js` 起動・画面遷移・描画ループ
- `src/game.js` 試合進行（ゾーン・スコア・リスポーン・設置物）
- `src/robot.js` 機体（プレイヤー/AI共通、入力は controls オブジェクト）
- `src/abilities.js` 通常攻撃・スキル・ウルト
- `src/ai.js` ボットAI（A*経路探索・ターゲット選定・スキル判断）
- `src/map.js` 都市マップ生成・衝突・視線・経路探索
- `src/conquest.js` チーム制圧モード（拠点・占拠ゲージ・チーム得点）
- `src/truesight.js` TrueSight（放射レイで可視範囲を求めマスク化、ワールドシェーダで暗転）
- `src/hud.js` / `src/ui.js` HUD・メニュー
- マルチプレイ化の際は `Robot.update(dt, controls)` にネットワーク入力を渡す形で拡張可能。
